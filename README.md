# AS3 Micromeros

Landing page da AS3 Engenharia / Plataforma Micromeros.

## Requisitos

- Node.js 18+
- npm

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

Depois acesse a URL exibida pelo Vite, normalmente:

http://localhost:5173

## Build

```bash
npm run build
```

## Preview do build

```bash
npm run preview
```

## Estrutura

- `src/components`: componentes React reutilizáveis
- `src/data`: dados da landing page
- `src/pages`: páginas
- `src/styles`: estilos
- `src/assets`: imagens e outros assets
